## ✅ 자가 점검 퀴즈 (5분)

다음 코드의 결과를 예측해보세요. 종이에 답을 적어보시고, 아래의 정답을 확인해주시기 바랍니다.

```typescript
// Q1
const { a = 10, b } = { b: 5 };
console.log(a, b);  // ?

// Q2
const original = { x: 1, y: 2 };
const copy = { ...original, y: 99 };
console.log(original.y, copy.y);  // ?

// Q3
const data = { user: null };
console.log(data?.user?.name ?? '익명');  // ?

// Q4
type Color = 'red' | 'green' | 'blue';
const c: Color = 'yellow';  // 어떻게 됨?
```

<details>
<summary>정답 확인하기</summary>

- **Q1**: `10 5`
  - 객체에 `a` 키가 없으니 기본값 `10` 적용. `b` 는 `5` 그대로.
- **Q2**: `2 99`
  - 스프레드는 새 객체를 만드므로 원본 `y` 는 그대로 `2`. 복사본은 `99`.
- **Q3**: `'익명'`
  - `data?.user` 가 `null` 이라 `name` 접근 시도 자체가 안 됨 (`undefined` 반환). `??` 가 `'익명'` 으로 fallback.
- **Q4**: 컴파일 에러 (`Type '"yellow"' is not assignable to type 'Color'`)
  - `Color` 타입이 정확히 세 값 중 하나만 받게 정의되어 있음.

각 문제별 관련 참고자료 번호:
- Q1 → 1번 (구조분해, 기본값)
- Q2 → 2번 (스프레드, 불변성)
- Q3 → 3번 (옵셔널 체이닝, nullish coalescing)
- Q4 → 8번 (리터럴 타입)

</details>
